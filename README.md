# Haunted House Tycoon

A deterministic park management game where you balance fear and profit.

[Track dev progress on Trello](https://trello.com/b/KlfRz1Fa/haunt-tycoon)

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173
